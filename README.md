# 게스트 안내 앱 — 껍데기

내 숙소의 게스트 안내 앱을 만들어 보는 빈 틀입니다. 글자만 바꾸면 내 집이 됩니다.

---

## 1. 내 것으로 복사하기

1. 이 페이지 오른쪽 위 **Fork** 를 누릅니다.
2. `Create fork` 를 누릅니다.
3. 내 계정 아래에 똑같은 리포가 하나 생깁니다. 이제부터는 내 것입니다.

원본은 그대로 있습니다. 무엇을 고쳐도 원본은 상하지 않습니다.

---

## 2. 인터넷에 올리기 (Vercel)

1. [vercel.com](https://vercel.com) 에 GitHub 계정으로 들어갑니다.
2. **Add New → Project** 를 누릅니다.
3. 방금 Fork 한 리포를 고르고 **Import** 를 누릅니다.
4. 아무것도 건드리지 말고 **Deploy** 를 누릅니다.
5. 1분쯤 뒤 주소가 하나 나옵니다. 그 주소가 내 앱입니다.

다음부터는 GitHub에서 파일을 고치고 저장하면 **저절로 다시 올라갑니다.**

---

## 3. 내 컴퓨터에서 열어 보기

화면 파일을 불러오는 방식이라 파일을 더블클릭해서 열면 빈 화면이 나옵니다.
아래처럼 작은 서버를 띄우고 여세요.

```
npx http-server -p 8000
```

그리고 브라우저에서 `http://127.0.0.1:8000` 을 엽니다.

---

## 4. 파일이 하는 일

| 파일 | 하는 일 | 얼마나 만지나 |
|---|---|---|
| `content.js` | 숙소 이름 · 주소 · 연락처 · 와이파이 · 좌표 · 가게 목록 | **여기만 만집니다** |
| `style.css` | 겉모습. 색과 글자 크기 | 색만 조금 |
| `screens/` | 화면 하나에 파일 하나 | 화면을 고칠 때 |
| `index.html` | 머리말 · 하단 탭 · 화면 불러오는 부분 | 거의 안 만짐 |
| `app.js` | 앱을 움직이는 부분 | 거의 안 만짐 |

**고칠 일이 생기면 `content.js` 를 먼저 여세요.** 열에 아홉은 거기서 끝납니다.

---

## 5. 화면 켜고 끄기

`content.js` 맨 위 `screens` 목록에 적힌 화면만 앱에 실립니다.

```js
screens: [
  'home',
  'hub',
  'checkin',
  // 'taxi',      ← 줄 앞의 //를 지우면 이 화면이 켜집니다
]
```

줄 앞의 `//` 를 지우면 켜지고, 붙이면 꺼집니다.
꺼진 화면으로 가는 버튼은 저절로 숨습니다. 파일은 `screens/` 폴더에 전부 들어 있습니다.

## 6. 지도

가게에 좌표를 넣기 전에는 지도가 나타나지 않습니다.
`content.js` 의 가게 항목에서 `lat` 과 `lng` 을 채우면 그때 지도가 켜지고,
좌표를 넣은 가게에만 핀이 찍힙니다. 핀을 누르면 아래 목록의 그 가게로 내려갑니다.

```js
lat: 37.5665, lng: 126.9780
```

좌표는 네이버 지도나 구글 지도에서 원하는 자리를 마우스 오른쪽으로 눌러 확인합니다.

## 7. 사진

`img/` 폴더의 그림은 전부 회색 네모입니다. 같은 이름으로 내 사진을 덮어쓰면 바뀝니다.

- `img/hero.jpg` 첫 화면의 큰 사진
- `img/logo.png` 로고
- `img/spots/` 동네 가게 사진

---

## 8. 언어

지금은 한국어만 들어 있어서 언어 버튼이 숨어 있습니다.
화면에 영어를 넣은 뒤 `content.js` 의 `languages` 에 `'en'` 을 더하면 버튼이 다시 나타납니다.

```js
languages: ['ko', 'en'],
```

## 9. 화면이 이상할 때

**하얀 화면이 뜨거나 "content.js를 읽지 못했습니다"가 나오면**
`content.js`에 글자 하나가 잘못된 것입니다. 화면이 몇 번째 줄인지 알려 줍니다.
거의 언제나 아래 셋 중 하나입니다.

- 줄 끝의 **쉼표**를 빠뜨림
- **따옴표**를 한쪽만 닫음
- 중괄호 `}` 나 대괄호 `]` 를 지움

**되돌리고 싶으면** GitHub에서 `content.js` 를 열고 오른쪽 위 **History** 를 누르면
고치기 전 상태가 그대로 남아 있습니다. 언제든 그때로 돌아갈 수 있습니다.

**어떤 화면만 안 보이면** `content.js` 의 `screens` 목록에서 이름이 맞는지 보세요.
`screens/` 폴더의 파일 이름과 똑같아야 합니다 (`checkin.html` → `'checkin'`).

**사진이 회색 네모로 보이면** 아직 내 사진을 넣지 않은 것입니다. 잘못된 게 아닙니다.
